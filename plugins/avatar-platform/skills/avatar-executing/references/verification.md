# 验证方法 (Step 3.4 步骤验证 + Step 4 完整性验证)

## Step 3.4 步骤验证

**验证方法**:

#### 编译验证
```bash
# Web
npm run build

# Android
./gradlew assembleDebug

# iOS
xcodebuild -scheme AvatarDemo -configuration Debug
```

#### 运行验证
```bash
# Web
npm run dev
# 打开浏览器，检查控制台

# Android
./gradlew installDebug
adb logcat | grep AVATAR

# iOS
# 在 Xcode 中运行，查看控制台
```

#### 功能验证
```yaml
SDK 初始化:
  - 检查: 返回成功/无错误日志
  - 预期: initialize 返回 SUCCESS

连接建立:
  - 检查: 收到 connected 事件
  - 预期: WebSocket 连接成功

视频播放:
  - 检查: 看到虚拟人画面
  - 预期: 3秒内出现首帧

文本驱动:
  - 检查: 虚拟人播报文本
  - 预期: 嘴唇动作与文本同步
```

## Step 4 完整性验证

### 4.1 端到端测试

**完整链路验证**:
```yaml
步骤 1: 启动应用
  - 检查: 无崩溃，无报错

步骤 2: 初始化 SDK
  - 检查: 日志显示初始化成功

步骤 3: 启动虚拟人
  - 检查: 3秒内看到画面

步骤 4: 文本驱动
  - 输入: "你好，欢迎使用虚拟人"
  - 检查: 虚拟人播报，嘴唇动

步骤 5: 文本交互（如需）
  - 输入: "你能做什么？"
  - 检查: 收到 NLP 回复并播报

步骤 6: 语音交互（如需）
  - 操作: 点击录音按钮说话
  - 检查: ASR 识别正确，虚拟人回复

步骤 7: 资源释放
  - 操作: 退出页面/Activity
  - 检查: 无内存泄漏，资源正确释放
```

### 4.2 异常场景测试

**网络异常**:
```yaml
场景: 断开网络后重连
  - 操作: 飞行模式开关
  - 预期: 显示连接中断，恢复后可重新连接
```

**权限异常**:
```yaml
场景: 拒绝麦克风权限
  - 操作: 系统设置拒绝权限
  - 预期: 友好提示，引导用户开启
```

**资源异常**:
```yaml
场景: 使用未授权的 avatarId
  - 操作: 修改 avatarId 为未授权值
  - 预期: 错误码 10120，提示未授权
```

### 4.3 性能验证

**关键指标**:
```yaml
首帧延迟:
  - 测量: start() 到首帧渲染时间
  - 目标: < 3秒

内存占用:
  - 测量: 运行时内存峰值
  - 目标: Web < 200MB, Android < 150MB, iOS < 120MB

帧率:
  - 测量: 播放器实际帧率
  - 目标: >= 20fps

播报延迟:
  - 测量: writeText 到虚拟人开口时间
  - 目标: < 500ms
```
