# Layer 2: 资源授权验证（所有平台必选）

## Step 2.1: 形象授权检查

**检查项**:
```yaml
必需资源:
  - avatarId: 形象ID

可选信息:
  - 形象类型: standard | hyperreal | live-photo
  - 是否支持透明背景
  - 是否支持动作控制
  - 可用动作列表
```

**检查方式**:
```
方式 1（推荐）: 查询平台 API
  - 请求 /api/v1/scenes/{sceneId}/avatars
  - 返回已授权形象列表及特性

方式 2（备选）: 测试连接判断
  - 使用 avatarId 发送 start
  - 错误码 10120: avatarId 未授权
  - 成功: avatarId 可用
```

**用户交互**:
```
检测到以下可用形象:
1. [118801001] 标准虚拟人-女性 (支持透明背景、动作控制)
2. [cnrmkf0001] 超拟人-男性 (不支持透明背景)

请选择或输入自定义 avatarId:
```

**PASS 标志**: avatarId 已授权且类型明确
**FAIL 处理**: 
```
avatarId 未授权 → 提示到控制台-接口服务-形象列表中授权
形象不存在 → 检查 ID 拼写或联系平台支持
```

## Step 2.2: 发音人授权检查

**检查项**:
```yaml
必需资源:
  - vcn: 发音人ID

可选信息:
  - 采样率: 16k | 24k
  - 是否支持变声
  - 语言: 中文 | 英文 | 多语言
```

**检查方式**: 同 Step 2.1

**用户交互**:
```
检测到以下可用发音人:
1. [x4_yezi] 叶子（女声、中文、16k）
2. [x4_lingfeng] 凌风（男声、中文、16k）

请选择或输入自定义 vcn:
```

**PASS 标志**: vcn 已授权
**FAIL 处理**: 提示授权路径
