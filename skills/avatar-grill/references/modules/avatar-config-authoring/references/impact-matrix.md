# 配置影响对照表

修改配置前，向用户说明影响。按配置项列出对性能 / 兼容 / 授权的影响。

| 配置项 | 性能影响 | 兼容影响 | 授权影响 | 修改后须知 |
|--------|---------|---------|---------|-----------|
| 分辨率 ↑ | CPU/GPU/带宽占用上升 | 移动端低配可能卡顿 | 无 | 需相应提高 bitrate |
| 分辨率 ↓ | 占用下降 | 画面变糊 | 无 | — |
| bitrate ↑ | 带宽占用上升 | 弱网易卡顿 | 无 | 必须 ≥200，推荐 2000 |
| bitrate ↓ | 带宽下降 | 画质下降；<200 直接报错 | 无 | 不得低于 200 |
| framerate ↑ | 占用上升 | — | 无 | 常用 25 |
| 换形象 (avatarId) | 无 | 超拟人不支持透明背景 | **需已授权，否则 10120** | 换前用 query-services 确认 |
| 换发音人 (vcn) | 无 | 与形象需匹配 | **需已授权** | — |
| TTS speed/volume/pitch | 无 | — | 无 | 实时生效，无需重连 |
| 透明背景开启 | 略增 | **需 xrtc 协议 + 非超拟人形象** | 无 | 协议不符则无效 |
| 换背景图 | 无 | — | 无 | — |

---

## 通用提醒

- **改完必须验证**：交接 `avatar-verification`，确认首帧链路（connected → stream_start）仍正常。
- **保留原值**：修改代码/配置时把原值以注释保留，便于回退。
- **区分调整 vs 排障**：若"改配置"是为了修复某个报错，应走 `avatar-troubleshoot`，
  由排障流程决定正确配置，而非在此盲改。
